# Assets e licenças

Todos os elementos visuais e sonoros deste projeto foram produzidos especificamente para
**Ecos da Mata** pelo script `tools/generate_assets.py`. Não há imagens, músicas, efeitos
sonoros ou código de terceiros copiados no projeto.

A única dependência de execução é `pygame-ce`, distribuída sob LGPL-2.1-or-later.
O empacotamento é feito com PyInstaller (GPL-2.0-or-later com exceção para distribuição de
aplicações). Consulte os respectivos projetos para os textos completos das licenças.
